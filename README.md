# Personal Finance & Budget Analysis

Analyzed personal financial data to understand income, expenses, savings, spending patterns, and monthly financial performance using Microsoft Excel.

## Analysis Performed

- Total Income Analysis
- Total Expenses Analysis
- Net Savings Analysis
- Savings Rate Analysis
- Total Transactions Analysis
- Average Expense Analysis
- Highest Expense Analysis
- Expense Category Analysis
- Monthly Income & Expense Analysis

## Dashboard

Built an interactive Excel dashboard to visualize key financial metrics, expense categories, and monthly income vs. expense trends.

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Analysis
- Data Visualization
- Conditional Formatting
- Dashboard Development
